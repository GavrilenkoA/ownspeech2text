# Device checklist (Galaxy Z Fold7, one pass)

Everything that only the phone can prove, in the order to run it (owner decision D12, `docs/DECISIONS.md`). Step ids
are **DC1-DC14** (not to be confused with the owner decisions D1-D12; DC11-DC13 were added in wave 1 and DC14 in wave 3
from the packages' device notes). Each step: command, time, expected output, what
decision it feeds. DC1-DC7 use scripts that already exist and need no app build; DC8-DC14 need the app built at the
end of wave 3 (`tools/device/murmur_app_smoke.sh`, WP-20). Owner of this file: WP-20 (handed over in wave 1; every
WP's device notes land here).

Before you start (5 min):
- Phone: unlock, Settings → About phone → Software information → tap Build number 7× → Developer options → USB
  debugging on. Settings → Security and privacy → Auto Blocker **off** (it blocks adb installs and USB commands).
  Keep the phone on the charger, screen timeout ≥ 10 min, Wi-Fi on.
- Host: `adb devices` shows exactly one device (`export ANDROID_SERIAL=<serial>` otherwise).
- Disk on the phone: ≥ 6 GB free (scripts push up to 3 GB and remove it afterwards).
- Send back the whole `.cache/device-reports/` and `.cache/device/` folders after the pass (no personal data; the
  OCR step stores screenshots of stock apps only, see DC7).

In wave 3 the real suite also dictates an English clip (with the Russian-only GigaAM: latency, not accuracy), reports
the stages after the stop (stop → Finishing → Polishing → Delivering → Done) per dictation, and checks that History,
Dashboard, Models and Settings show the data of those dictations; `--suite bench` runs the app's own benchmark runner
on the real CPU processes (WP-14's entry point); `--suite wiring` runs the container tests on the merged app. Emulator limits that stay
on the phone: the microphone cannot be fed (the emulator runs a debug WAV capture instead, DC5/DC8 use the real mic);
headless `-no-window` does not shrink the display on the hinge event (TOOLCHAIN 4.5), so the real fold is DC10;
Samsung's call UI and One UI's notification panel differ from AOSP (DC10).
